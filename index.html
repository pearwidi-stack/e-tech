🎯 Tujuan Pembelajaran

  • Melakukan konfigurasi IP statik pada Debian Virtual Machine.
  • Menginstal dan mengkonfigurasi layanan FTP (ProFTPD) melalui repository CD/DVD.
  • Melakukan uji coba koneksi dan transfer file dari klien (Windows) ke Server (Debian) menggunakan FileZilla.

📋 Persyaratan Prasyarat

  • Aplikasi VirtualBox / VM sudah terinstal.
  • File ISO Debian 10 (CD 1, 2, dan 3).
  • Aplikasi klien FTP seperti FileZilla atau WinSCP di komputer host.

📖 Materi Utama: Step-by-Step

Langkah 1: Konfigurasi Jaringan & IP Server

Pastikan settingan jaringan di VirtualBox menggunakan Host-only Adapter. Nyalakan Debian dan login. Kemudian, edit file konfigurasi jaringan untuk membuat IP statik:

nano /etc/network/interfaces

Masukkan IP statik berikut (Address: 192.168.10.20, Netmask: 255.255.255.0). Simpan dengan Ctrl+X lalu Y dan Enter. Restart jaringan dan cek IP:

/etc/init.d/networking restart
ip a

💡 PRO-TIP:
Pada komputer Host (Windows), pastikan IP VirtualBox Host-Only Network diset beda di oktet terakhir (misal: 192.168.10.21). Sebelum melakukan ping, matikan (off) Firewall Windows dan nyalakan (on) File Sharing, kecuali password sharing dimatikan (off). Lakukan uji ping dua arah antara Windows dan Debian.

Langkah 2: Instalasi ProFTPD via Repository CD

Karena menggunakan repository offline, kita harus memasukkan ISO Debian satu per satu. Mulai dengan memasukkan CD 1 Debian (Devices => Optical Devices => CD 1). Jalankan perintah berikut secara berurutan:

apt-cdrom add
apt-get update
apt-get upgrade

Lakukan hal yang sama untuk CD 2 (masukkan CD, lalu jalankan ketiga perintah di atas). Setelah selesai, instal paket FTP server (ProFTPD):

apt-get install proftpd (Tekan Y lalu Enter)

[Gambar Placeholder: Tampilan pemilihan mode instalasi ProFTPD (pilih standalone)]

Langkah 3: Konfigurasi File ProFTPD

Buka file konfigurasi ProFTPD dengan perintah:

nano /etc/proftpd/proftpd.conf

Lakukan perubahan baris berikut di dalam file tersebut:

  • Ubah IPv6 dari On menjadi Off.
  • Ubah waktu timeout: 6000 menjadi 600, dan 12000 menjadi 1200.
  • Hilangkan tanda pagar (#) pada baris DefaultRoot.
  • Ubah Port dari 21 menjadi 22.
  • Cari baris #<anonymous ~ftp> dan kata User, hilangkan tanda pagar (#) di awal baris tersebut.
  • Cari baris penutup #</anonymous> terakhir, hilangkan tanda pagarnya.

Simpan file (Ctrl+X, Y) dan restart layanan ProFTPD:

/etc/init.d/proftpd restart

[Gambar Placeholder: Perbandingan isi file proftpd.conf Sebelum dan Sesudah Dirubah]

Langkah 4: Pembuatan User & Uji Coba Klien

Buat user baru untuk login ke FTP server. Misalnya kita buat user bernama "joko":

adduser joko

Masukkan password (misal: 1234) dan masukkan kembali passwordnya. Tekan enter terus sampai muncul pilihan Y/N, pilih Y dan Enter.

Buka aplikasi FileZilla di komputer Windows Anda. Masukkan data koneksi berikut:

  • Host: 192.168.10.20
  • Username: joko
  • Password: 1234
  • Port: 22

Klik Quickconnect. Jika muncul popup, klik OK. Jika berhasil, Anda akan melihat direktori server di sebelah kanan.

💡 PRO-TIP:
Untuk memastikan file transfer berfungsi, coba pindahkan file dari komputer Windows (panel kiri FileZilla) ke direktori server Debian (panel kanan). Anda bisa mengeceknya di Debian melalui terminal dengan perintah: cd /home/joko/ lalu ketik ls untuk melihat isi direktori.

📦 Poin Kunci / Takeaway

🌟 Ringkasan Pertemuan
  • IP Host-only: IP server dan IP komputer host harus berada di subnet yang sama agar bisa saling terhubung.
  • Repository CD: Gunakan apt-cdrom add setiap kali mengganti ISO Debian untuk memperbarui database paket offline.
  • Keamanan Dasar: Penggunaan DefaultRoot mengunci user FTP hanya ke folder home masing-masing, mencegah akses ke root sistem.
  • Pengujian: Selalu lakukan uji coba transfer file untuk memastikan layanan FTP berjalan dua arah.
