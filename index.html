MATERI ADMINISTRASI SISTEM JARINGAN

Konfigurasi FTP Server pada Debian 10 menggunakan VirtualBox. Pelajari cara menginstal, mengkonfigurasi, dan melakukan uji coba transfer file dengan aman.

🎯 Tujuan Pembelajaran

  • Melakukan konfigurasi IP statik pada Debian Virtual Machine.
  • Menginstal dan mengkonfigurasi layanan FTP (ProFTPD) melalui repository CD/DVD.
  • Melakukan uji coba koneksi dan transfer file dari klien (Windows) ke Server (Debian) menggunakan FileZilla.

📋 Persyaratan Prasyarat

  • Aplikasi VirtualBox / VM sudah terinstal.
  • File ISO Debian 10 (CD 1, 2, dan 3).
  • Aplikasi klien FTP seperti FileZilla atau WinSCP di komputer host.

📖 Materi Utama: Step-by-Step

Langkah 1: Konfigurasi Jaringan & IP Server

Pastikan settingan jaringan di VirtualBox menggunakan Host-only Adapter. Edit file konfigurasi jaringan untuk membuat IP statik:

nano /etc/network/interfaces

Masukkan IP statik (Address: 192.168.10.20, Netmask: 255.255.255.0). Simpan Ctrl+X, Y, Enter. Restart jaringan:

/etc/init.d/networking restart
ip a

💡 PRO-TIP:
Pada komputer Host (Windows), pastikan IP VirtualBox Host-Only Network diset beda di oktet terakhir (misal: 192.168.10.21). Sebelum ping, matikan Firewall Windows dan nyalakan File Sharing. Lakukan uji ping dua arah.

Langkah 2: Instalasi ProFTPD via Repository CD

Masukkan CD 1 Debian (Devices => Optical Devices => CD 1). Jalankan perintah berikut:

apt-cdrom add
apt-get update
apt-get upgrade

Lakukan hal yang sama untuk CD 2. Setelah selesai, instal paket FTP server:

apt-get install proftpd (Tekan Y lalu Enter)

Langkah 3: Konfigurasi File ProFTPD

Buka file konfigurasi: nano /etc/proftpd/proftpd.conf

  • Ubah IPv6 dari On menjadi Off.
  • Ubah timeout: 6000 menjadi 600, dan 12000 menjadi 1200.
  • Hilangkan tanda pagar (#) pada baris DefaultRoot.
  • Ubah Port dari 21 menjadi 22.
  • Cari baris #<anonymous ~ftp> dan kata User, hilangkan tanda pagarnya.
  • Cari baris penutup #</anonymous> terakhir, hilangkan tanda pagarnya.

Simpan dan restart: /etc/init.d/proftpd restart

Langkah 4: Pembuatan User & Uji Coba Klien

Buat user baru: adduser joko (masukkan password 1234).

Buka FileZilla di Windows. Masukkan: Host: 192.168.10.20, Username: joko, Password: 1234, Port: 22. Klik Quickconnect.

💡 PRO-TIP:
Coba pindahkan file dari Windows ke Server. Cek di Debian dengan: cd /home/joko/ lalu ls.
🌟 Ringkasan Pertemuan
  • IP Host-only: IP server dan host harus 1 subnet.
  • Repository CD: Gunakan apt-cdrom add setiap kali ganti ISO.
  • Keamanan: DefaultRoot mengunci user di folder home masing-masing.

KONFIGURASI OPEN SSH SERVER & TELNET

Pelajari cara meremote server Debian dari komputer jarak jauh menggunakan protokol SSH (Secure Shell).

🎯 Tujuan Pembelajaran

  • Memahami konsep remote server menggunakan protokol SSH.
  • Menginstal dan mengkonfigurasi paket OpenSSH Server pada Debian.
  • Melakukan uji coba koneksi remote dari komputer Windows menggunakan CMD dan aplikasi PuTTY.

📖 Materi Utama: Step-by-Step

Langkah 1: Cek Koneksi Internet & IP

Pastikan Debian menggunakan Bridge Adapter dan mendapat IP DHCP. Cek koneksi internet:

ping 8.8.8.8

Jika reply, cek IP Debian dan catat (misal: 192.168.52.251): ip a

Langkah 2: Instalasi OpenSSH Server

apt install openssh-server

💡 PRO-TIP:
Jika gagal, masukkan CD 1 Debian ke VirtualBox, jalankan apt-cdrom add, lalu coba instal lagi.

Langkah 3: Konfigurasi SSH

nano /etc/ssh/sshd_config

  • Hilangkan tanda pagar (#) pada baris #Port 22 menjadi Port 22.
  • Ubah #PermitRootLogin menjadi PermitRootLogin yes.

Simpan & restart: /etc/init.d/ssh restart lalu cek status systemctl status ssh

Langkah 4: Uji Coba Remote dari Windows

1. Menggunakan CMD: ssh root@192.168.52.251 (masukkan password root).

2. Menggunakan PuTTY: Buka PuTTY, masukkan IP Debian, pilih SSH, klik Open. Login sebagai root.

🌟 Ringkasan Pertemuan
  • Bridge Network memungkinkan VM mendapat IP dari router fisik.
  • Port 22 adalah port standar SSH.
  • PermitRootLogin yes mengizinkan login root dari jauh.

KONFIGURASI DHCP SERVER

Pelajari cara memberikan alamat IP secara otomatis kepada komputer klien dalam sebuah jaringan lokal.

🎯 Tujuan Pembelajaran

  • Konfigurasi IP statik pada interface internal Debian.
  • Menginstal dan mengkonfigurasi paket ISC-DHCP-Server.
  • Uji coba permintaan IP otomatis dari komputer klien Windows.

📖 Materi Utama: Step-by-Step

Langkah 1: Konfigurasi IP Internal

nano /etc/network/interfaces

Tambahkan IP statik untuk interface internal (misal: enp0s8):

auto enp0s8
iface enp0s8 inet static
address 200.200.1.1/24

Simpan & Restart: /etc/init.d/networking restart

Langkah 2: Instalasi DHCP Server

Masukkan CD 2 Debian, lalu jalankan:

apt-cdrom add
apt-get update
apt install isc-dhcp-server (Tekan Y)

Langkah 3: Konfigurasi Default Interface

nano /etc/default/isc-dhcp-server

Isi nama interface internal di antara tanda kutip: INTERFACESv4="enp0s8"

Langkah 4: Konfigurasi Pool DHCP

nano /etc/dhcp/dhcpd.conf

Tambahkan konfigurasi subnet di bagian kedua file:

subnet 200.200.1.0 netmask 255.255.255.0 {
range 200.200.1.50 200.200.1.60;
option routers 200.200.1.1;
}

Simpan & Restart: /etc/init.d/isc-dhcp-server restart

Langkah 5: Uji Coba di Windows

💡 PRO-TIP:
1. Reset VM Windows (Machine -> Reset).
2. Disable lalu Enable adapter LAN di Windows.
3. Buka CMD Windows: ipconfig /release lalu ipconfig /renew. Cek apakah IP sudah berubah menjadi 200.200.1.50.
🌟 Ringkasan Pertemuan
  • DHCP mempermudah administrasi jaringan dengan membagikan IP otomatis.
  • Range IP menentukan batas IP yang akan dibagikan ke klien.

KONFIGURASI DNS SERVER (BIND9)

Pelajari cara menterjemahkan nama domain (seperti pear.net) menjadi alamat IP agar mudah diingat oleh manusia.

🎯 Tujuan Pembelajaran

  • Menginstal dan mengkonfigurasi Bind9 sebagai DNS Server lokal.
  • Membuat Forward dan Reverse Zone untuk domain lokal (pear.net).
  • Melakukan pengujian DNS melalui perintah NSLookup dan Web Browser.

📖 Materi Utama: Step-by-Step

Langkah 1: Setting IP & Instalasi Bind9

Setting IP Debian menjadi 20.20.20.1 (Host-only). Lalu install bind9:

apt install bind9 dnsutils (Gunakan CD 1/2 jika diminta)

Langkah 2: Copy File Zone

Masuk ke direktori bind: cd /etc/bind/

Copy file forward dan reverse:

cp db.local db.pear
cp db.127 db.20 (20 diambil dari oktet pertama IP)

Langkah 3 & 4: Konfigurasi Forward & Reverse Zone

Edit Forward: nano db.pear (Ubah "localhost" menjadi "pear.net." dan masukkan IP 20.20.20.1 pada record A).

Edit Reverse: nano db.20 (Ubah "localhost" menjadi "pear.net." dan masukkan angka akhir IP (1) pada record NS dan PTR).

Langkah 5: Deklarasikan Zone di Named.conf

nano named.conf.default-zones

Tambahkan di bagian bawah:

zone "pear.net" { type master; file "/etc/bind/db.pear"; };
zone "20.20.20.in-addr.arpa" { type master; file "/etc/bind/db.20"; };

Langkah 6: Setting Resolv.conf & Restart

nano /etc/resolv.conf (Isi: nameserver 20.20.20.1, search pear.net)

Restart Bind9: /etc/init.d/bind9 restart

Langkah 7: Uji Coba DNS

Di Debian ketik: nslookup pear.net

Di Windows: Seting IP adapter agar menggunakan DNS Server 20.20.20.1. Buka CMD ketik nslookup pear.net.

🌟 Ringkasan Pertemuan
  • Forward Zone menterjemahkan Nama ke IP, Reverse Zone sebaliknya.
  • Resolv.conf mengatur server mana yang ditanyakan saat Debian butuh DNS.

KONFIGURASI WEB SERVER (APACHE2)

Pelajari cara menyajikan halaman web HTML sederhana yang dapat diakses melalui jaringan lokal.

🎯 Tujuan Pembelajaran

  • Menginstal web server Apache2 pada Debian.
  • Mengkonfigurasi Virtual Host untuk domain lokal.
  • Membuat halaman web (index.html) sederhana dan mengujinya di browser klien.

📖 Materi Utama: Step-by-Step

Langkah 1: Instalasi Apache2

Setting IP Debian 10.10.10.1. Lalu install:

apt install apache2 (Tekan Y, masukkan CD 1 jika diminta).

Cek status: dpkg -l apache2

Langkah 2: Konfigurasi Virtual Host

Masuk direktori: cd /etc/apache2/sites-available

Salin config default: cp 000-default.conf pear.conf

Edit file: nano pear.conf (Ubah ServerAdmin menjadi email Anda). Simpan.

Langkah 3: Aktifkan Site Baru

Nonaktifkan default: a2dissite 000-default.conf

Aktifkan pear.conf: a2ensite pear.conf

Langkah 4: Edit Halaman Web (index.html)

Masuk direktori web: cd /var/www/html/

Edit file: nano index.html

Hapus semua teks komentarnya (blok dengan Ctrl+Shift+Panah Bawah, lalu Ctrl+K hapus). Ketik:

<html>
WELCOME TO MY CHANNEL
<br/>
Dont forget to follow and subscribe
<html/>

Simpan, lalu restart Apache: /etc/init.d/apache2 restart

Langkah 5: Uji Coba Web

Buka Browser (Chrome/Mozilla) di Windows. Ketik di URL: 10.10.10.1 dan tekan Enter.

🌟 Ringkasan Pertemuan
  • Apache2 adalah web server paling populer untuk Linux.
  • Virtual Host (a2ensite/a2dissite) digunakan untuk mengatur banyak website dalam satu server.

KONFIGURASI DATABASE SERVER (MariaDB)

Pelajari dasar-dasar manajemen database relasional menggunakan SQL (Structured Query Language).

🎯 Tujuan Pembelajaran

  • Menginstal dan mengamankan database server MariaDB.
  • Memahami perintah dasar SQL untuk membuat database dan tabel.
  • Melakukan operasi CRUD (Create, Read) sederhana.

📖 Materi Utama: Step-by-Step

Langkah 1: Instalasi & Sekuriti MariaDB

Install paket: apt install mariadb-server (Gunakan CD 1/2 jika diminta).

Cek status: systemctl status mariadb.service

Jalankan sekuriti setup: mysql_secure_installation (Tekan Enter, ketik Y, buat password root, lalu tekan Y sampai selesai).

Langkah 2: Masuk ke Database

Login ke MariaDB: mysql -u root -p (Masukkan password yang dibuat tadi).

Lihat database default: show databases;

Langkah 3: Membuat Database & Table

Buat database baru: create database smk_bisa;

Gunakan database tersebut: use smk_bisa;

Buat tabel siswa:

create table siswa(id int auto_increment, nama_siswa varchar(100), primary key(id)) engine=innodb;

Lihat tabel: show tables;

Langkah 4: Memasukkan Data (Insert)

insert into siswa (nama_siswa) values("jaka");

insert into siswa (nama_siswa) values("bambang");

Langkah 5: Melihat Data (Select)

Tampilkan seluruh isi tabel siswa: select * from siswa;

💡 PRO-TIP:
Jangan lupa untuk selalu memberi tanda titik koma (;) di akhir setiap perintah SQL. Jika lupa, perintah tidak akan dieksekusi.
🌟 Ringkasan Pertemuan
  • mysql_secure_installation sangat penting untuk mengatur password root dan menutup celah keamanan.
  • Auto Increment secara otomatis menambah nomor ID setiap ada data baru dimasukkan.
